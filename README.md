# C'est pas le mot que tu crois

Mots croisés multijoueur en temps réel : deux joueurs font la course sur la même grille, mi-mots classiques, mi-argot.

## Lancer en local
```bash
npm install
npm run dev
```
Puis ouvrir http://localhost:3000

## Stack
Node.js, Express, Socket.io, HTML/CSS/JS natifs. Déployé sur Render.

Règles du jeu : `docs/brief.md`. Avancement : `docs/roadmap.md`.
